# node-express

Exercícios de Node.js e Express com páginas estáticas e rotas introdutórias.

Projeto desenvolvido para fins educacionais.

**Tecnologias:** `Express`, `HTML`, `JavaScript`, `Node.js`.

## Executar localmente

```bash
npm install
npm run start
```
